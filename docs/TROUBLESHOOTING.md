# Troubleshooting

Access denied: verify active user email, role, deployment audience. No tasks: verify department assignment and workflow state. No activation: inspect task status/history/audit and workflow configuration. Missing alert/email: run monitor/processor manually, inspect triggers/settings/notifications. Stale reports: run `rebuildReportingData()`. Schema mismatch: restore canonical headers only after backup. Trigger/backup failure: check execution log and Drive permissions.
