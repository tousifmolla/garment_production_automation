# Go-live checklist

The completed v1.0 release record is maintained in the repository-root [GO_LIVE_CHECKLIST.md](../GO_LIVE_CHECKLIST.md). Use this operational document for future release checklists: mark system readiness, security, admin/department access, workflow, triggers, notifications, backup/recovery, reporting, Power BI refresh, and deployment version as PASS, FAIL, or NOT TESTED. Do not mark a future release ready while any required real-environment item is NOT TESTED.
