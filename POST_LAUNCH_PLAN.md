# Post-Launch Plan — v1.1 Backlog

## Power BI

1. Production Tracking page: order detail table, status/priority/date slicers, completed-versus-WIP analysis.
2. Department Performance page: completed, pending, overdue, throughput, and completion-time visuals.
3. Delivery Performance page: on-time delivery, delay analysis, active/completed order views.
4. Cycle Time / Bottlenecks page: stage duration, bottleneck ranking, and order/stage matrix.
5. Evaluate optional Power BI row-level security after confirming audience and ownership requirements.

## Application improvements

1. UI polish and responsive performance improvements.
2. User feedback enhancements, including clearer operational guidance and error messages.
3. Review Apps Script execution quotas, spreadsheet growth, alert volume, and refresh duration after initial operational usage.

## Operating cadence

- Daily: review overdue/blocked tasks, critical alerts, and notification failures.
- Weekly: verify the newest backup and review delivery exceptions.
- Monthly: review users, departments, workflow/settings changes, reporting refresh health, and recovery readiness.

Every v1.1 item requires scoped design, regression tests, and an approval before deployment. Do not use the v1.1 backlog to bypass v1.0 production controls.
