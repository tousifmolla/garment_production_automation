# Garment Production Automation v1.0

**Release status:** Production-ready release freeze  
**Release date:** 2026-09-02  
**Schema version:** 1.0.0

Version 1.0 is the frozen operational release. It includes the Admin web app, department dashboards, the six-stage production workflow, task quantity tracking, alerts, notifications, reporting, backup/recovery controls, and the accepted Executive Power BI dashboard.

The approved workflow is Purchase → Cutting → Stitching/Making → Finishing → Packaging → Selling. Production changes require a new versioned release after this freeze.

Power BI scope in v1.0 is limited to the Executive Dashboard and its validated baseline KPI cards. Additional report pages are planned for v1.1.
